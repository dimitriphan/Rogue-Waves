Rogue Waves {VERSION}
An expansion for TDS - Tower Defense Strategy, by Dimitri.

What is in this release
  Yossele, The Patient Golem: a new vessel. Yossele shoots a green laser from its mouth, and its buildings grow a
  stage stronger for every Tide they survive. Play it in any normal game, on your own or online.
  The Rogue Waves mode, more vessels and new foes come in later releases of this same pack.

Install
  1. Unzip this file into the game's Mods folder, so that you have TDS\Mods\RogueWavesMod.
     (Steam > TDS > Manage > Browse local files shows the TDS folder. Make the Mods folder if it isn't there.)
  2. Start the game and turn Rogue Waves on in Main Menu > Extras > Mods.
  3. Restart the game. The game loads mods only at start, and turning a mod off does nothing until a restart.
  If you had a YosseleMod from a test build, remove it from the Mods folder first: the two can't be on together.

Update
  Delete TDS\Mods\RogueWavesMod, then unzip the new version the same way. Each new release adds to this one mod.

Online
  Every player in a lobby needs this pack, at the same version. A modded lobby doesn't count for the leaderboards.

Uninstall
  Turn it off in the Mods menu and restart the game, or delete TDS\Mods\RogueWavesMod.
