# Editing the kit

The kit is the single source of truth, so a fact lives in one chapter and the others link to it. Add pitfalls as the
next number in `docs/09`. Mark each claim as verified in a mod, read from the game's code, or untested. Keep the map in
`TDS_Vessel_Creator/README.md` and the "Facts about this PC" table current. Keep the existing style: tables, short sections, lines wrapped at 120 columns.
