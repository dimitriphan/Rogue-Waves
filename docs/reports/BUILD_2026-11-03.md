## 4. What the in-game checks caught

Compiled code passed none of these by itself. Each was found by playing it and is fixed:

| Found | What it would have done | Fix |
| --- | --- | --- |
| The chart's camera looked at the sky | an empty blue screen for the whole chart | camera along its forward (pitfall #124) |
| The chart's islands were scaled to fit, with primitive discs | they read as toys, some as huge shapes in the Setup close-up | stock islands at their own size, turned to the camera, with their own docks |
| The menu button's clone took all five of Play's images and pushed More and Exit off the screen | a broken menu | a tile beside Play; only its picture changes (pitfall #126) |
| Everything between Tides ran one row off the Tide table | the shop at a Tide's start; a 54-pass run didn't show it | the row is `Entry - 1` (pitfall #121) |
| **A destroyed nest stopped the Tides for good** | Raze the Nest, or any stock nest razed in a Rogue Waves map, froze the map with no error | its hook goes with it (pitfall #123) |
| Beat the Clock could never be won | a Tide's clock runs out whatever happens | it watches for a clear field with a quarter of the clock left (pitfall #122) |
| Cheap Refits missed new towers | it did nothing | kept up twice a second (pitfall #130) |
| Bottom Rock was on sale under another id | all aura pay down to 1% | left off the shelf (pitfall #132) |
| The end screen could read "BASIN BREACHED" on a win | about one run in two | the title is written on the screen as well (pitfall #129) |
| The vote's calm maps had specks for pictures | four identical tiles | each map's own glyph, at the cards' scale (pitfall #125) |
| The Direction pick opened in the fly-in, invisible | the picks ran out unseen | waits for the vessels and the fly-in (pitfall #127) |
| The no-mods warning named the host | a false warning | pitfall #128 |
| After a loss the party had to steer back by hand | not wrong, but unlike a vote's trip | the boat sails back by itself |

## 6. Limits I know of

- **Online** is untested: the votes, Fund Transfer between two players, a friend's Direction and Cardinal save, the no-mods warning with a real friend. Every sync path has been run solo, host side. One evening with a friend (kit `docs/19` §8).
- **Look by eye:** the captures look right to me, but the chart, VENDCINT, Uloe and the rings on modified foes are yours to judge. All of it but the stock art is temporary.
- **Base vessels' Directions:** one of the five (Smacky's) was measured; the others take the same code path with another stat.
- **Vessel Directions:** their effects are in each vessel's self-test as far as it goes; Sewing Machine has no panel name of its own, Bonsai stays seed-firing under both Tree Directions, and Direct Line and seed upgrades go inert under them (`IMPLEMENTATION_NOTES.md` of Spool and Yossele).
- **Dazzling** doesn't use Uloe's Light; it has its own debuffs (the foes' README).
- **Uloe's self-test** sometimes can't set up three of its checks (the burst's numbers, Bounce Card, Long Throw) on a given placement: it reports setup, not a fail, and they passed the run before.
- **DOTween's safe mode** logs "errors inside callbacks" in the campaign's flow (1,412 in the longest run, none in a chart or map-load round alone). Nothing visibly goes wrong. The count rises with the chart's weather billboards shown before a scene change, which is my reading, not yet proven: DOTween's own log can't be reached from a mod.
- **Quickening Current, Rising Water, Nesting Ground** were already seen in earlier rounds and pass again. A flooded map's look is still yours.
- **A win by a full 10 maps in real play** hasn't been played out: maps 1 and 2 were played, the rest on pretend results.
