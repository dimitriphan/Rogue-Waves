| Rogue Wave Mode |
	The Rogue Wave is an expansive mod revolving around roguelike mechanics and new content. New vessels and cardinals are included, along with a new roguelike mode. In this mode, players join together and play a campaign of 10 maps in a row with increasing difficulty and new modifiers / enemies that change with each campaign. Progress is saved between maps, so a campaign can be played over several sessions. Players can empower themselves using new mechanics and upgrades, purchasable with a new currency found in game from doing objectives given to the player. Completing a campaign unlocks a harder difficulty modifier for future campaigns. Score does not count in this mode.
	/ Ascension levels are named Depth 1, Depth 2 and so on, and are meant to carry over between sessions \
	# 5 Depth levels. Each one adds a change along with the previous depth levels.
	/ Depth's design still waits until the core gameplay loop is settled (2026-10-09) \
	# Each map is harder than the one before: more enemy modifiers, higher spawn rates, harder optional objectives and more enemy health.
	! NEEDS WHICH MODIFIERS AND ENEMIES CAN CHANGE FROM CAMPAIGN TO CAMPAIGN !
	# Losing a map uses one of a limited number of retries: the team replays that map from the last save. With no retries left, a lost map ends the campaign. Quitting during a map counts as losing it.
	# A campaign gets 3 retries.

| Gameplay Rundown |
	Players are first grouped together in a host's campaign, where players must select their vessel first before the Rogue Wave begins as they are locked into their choice. The host starts a campaign from the Rogue Wave button on the main menu (New or Continue), which takes them to the boat with the mode already set, and invites friends there. After all players are ready, the Rogue Wave begins and each player is given a choice of 3 new upgrades called [Direction] and picks 1. These upgrades range from tower stat increases, to major gameplay alternations that fundamentally change how a Vessel plays. Once each player selects their [Direction], players are then given a choice of 3 maps from the base game which are then voted on. Every map is voted on, the first map included. Once in game, gameplay remains similar with new objectives that tie into the new currency [Pure Aura] and shop mechanic. [Pure Aura] is earned each tide, with optional objectives that players can take on for bonus [Pure Aura], similar to the bounty mechanic from the base game. By completing these objectives, players earn extra [Pure Aura] which can be traded with to the shopkeeper {VENDCINT} inbetween waves for [Cardinals] or ranks of [Directions] they already hold. After successfully reaching Tide 15, the players vote between tides on leaving, and the map is left when a majority votes to. However, staying bonus tides allows the player to accumulate more [Pure Aura], and bonus tides go on, each one harder, until a majority votes to leave. The players are only able to leave between tides, so they are not able to exit right before their demise. The loop then continues map after map of choosing a direction, playing the map, and escaping for a total of 10 maps with increasing difficulty. Between maps the campaign is saved: the players can stop there and continue later, and when the host picks the campaign up again with Continue on the main menu's Rogue Wave button each player gets back their vessel, [Pure Aura], [Directions] and [Cardinals]. If the players clear Tide 15 on the final map and leave it, they complete the campaign and a new ascension level is unlocked. A failed campaign keeps nothing.
	/ Model Lighthouse, your name for the old start Cardinal, is kept for a later Cardinal or item \
	# Every base game map can be offered in the vote. / Never the custom map slot, which hangs while loading \
	# Leaving after Tide 15 is a majority vote, taken between tides.
	# Bonus tides have no limit. They go on, each one harder, until a majority votes to leave. Map 10 ends the same way, so the campaign is won by leaving map 10 after Tide 15 or later.
	# A failed campaign keeps nothing.

| New Mechanics |
	[Directions]
		A new gameplay altering mechanic specific to each player. Directions can provide normal bonuses to characters, or create fundamental changes to how a vessel functions.
		- 3 are offered and 1 is picked before each map. The shop sells only the next rank of a Direction the vessel already holds.
		- A Direction a player already holds can be offered again as its next rank (II, III) / So about 7 for every vessel and 4 per new vessel last a 10-map campaign \
		- Named like a heading or a course / Deep Roots, Loose Threads, Hard to Port \
		- Each player's Directions sit on their own vessel and come back at the start of every map. They are saved with the campaign.
		/ Use the New Direction template at the bottom of this file to add one \
		/ The list of Directions for each vessel lives in Directions by Vessel at the bottom \
		- Base game vessels get their own Directions too, besides the Any ones.

	[Pure Aura]
		A new currency earned in game to purchase [Directions] and [Cardinals]. Can be earned by surviving tides and by accepting and completing optional objectives. Each player has their own amount of [Pure Aura].
		- Shown as a pearl white counter on each player's vessel, a colour none of the base auras use.
		- Every tide pays 3 [Pure Aura]. A bonus tide pays 2.

	[Fund Transfer]
		Players are able to send each other a limited amount of aura inbetween waves at {VENDCINT}, allowing for more cooperative play and specialization into roles.
		- This is the expansion's "Streamlined Economy Changes".
		- Only base aura can be sent, never [Pure Aura].
		- Each player can send up to 50 times the coming tide's number per break, in any mix of colours: 50 before Tide 1, and 250 in the break before Tide 5 (125 red and 125 blue, or 250 blue).

	[Shopkeeper]
		{VENDCINT} / A sentient vending machine \
		- A unit that falls from the sky near the vessels' spawn point at the start of every break between tides, the way the vessels land.
		- At the end of the break it jumps into the sky and disappears.
		- Sells [Cardinals], and the next rank of [Directions] the vessel already holds, for [Pure Aura]. [Fund Transfer] is done at it too.
