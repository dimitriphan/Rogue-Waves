	- Goes in: 12_Cardinals.txt, under its kind
	# Names follow the pack's style sheet: a Cardinal is two plain words for a found object. /~ docs/STYLE.md \

	{Name of Cardinal} / Two plain words, a found object the wave washed up \
		- Kind: / Vessel or Team. Vessel acts only on the buyer's vessel, towers, units or aura. Team acts on the core, the enemies or the Tide clock, for every player \
		- In-game line: / One line as the game shows it, no numbers, like the base game's Cardinals \
		- Numbers: / Exact values. Leave blank and the design gate proposes them \
		- Lasts: / The rest of the campaign, this map only, or a number of Tides \
		- Stacks: / Yes if a player (or the team) can own more than one, with no limit; no if it leaves the shop once owned \
		- Where from: / Shop, a reward, or the lobby too (a lobby Cardinal needs an unlock: say how it is unlocked) \
		- Colour: / Red, Blue, Yellow, Green or Mixed: its lobby slot and the colour of its card in the shop \
		- Cost: / In Pure Aura \
		- Look: / The object for its icon, readable at 12x12, in the pack's palette \
		- Clashes: / Anything it should not touch: retries, the leave choice after Tide 15, shop breaks, [Fund Transfer], or none \

	# Names are a short order, like a bounty on a notice board.

	{Name of Objective} / A short order, like a bounty on a notice board \
		- Kind: / Hunt (kill a number of one enemy, maybe with a modifier), Guard (keep the core or a building from harm), Hold (no enemy reaches a spot), Rush (finish before a time runs out), Mining (fully mine a node), or something new \
		- In-game line: / One line the player reads when it is offered: what to do, no numbers \
		- Numbers: / The count, time or limit. Leave blank and the design gate proposes them \
		- Taken by: / One player, who alone is paid, or the team, where every player earns the full pay \
		- Offered: / When it can be taken: every break at {VENDCINT}, once a map, or from a set tide \
		- Lasts: / The next tide, a number of tides, or the rest of the map \
		- If failed: / Nothing, or a cost: say what \
		- Later maps: / How it gets harder on later maps: bigger counts, a modifier on the targets, a shorter time \
		- Pays: / In Pure Aura, and any base aura on top \
		- Look: / One found object for its icon, readable at 12x12 \
		- Clashes: / Any Cardinal, Direction or modifier it should not be offered with, or none \
