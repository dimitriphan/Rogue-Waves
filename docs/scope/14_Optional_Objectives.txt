	# The rules for optional objectives, and the Optional Objective List: each objective in the Optional Objective template from 15_Templates.txt.
	! NEEDS LIST OF OPTIONAL OBJECTIVES AND WHAT EACH ONE PAYS !

	[Rules]
		- Names: a short order, like a bounty on a notice board
		- Offered: a new objective is offered at {VENDCINT} in every break between tides
		- Team pay: an objective the team takes pays every player the same, full amount
		- Like: optional objectives that players can take on for bonus [Pure Aura], similar to the bounty mechanic from the base game

	[Optional Objective List]
		{Mind the Meteor}
			- Kind: Mining
			- In-game line: Fully mine a node that spawns in a random location on the map.
			- Numbers: 12 hits + 3 per map; about 8 tiles + 1.5 per map from the Basin
			- Taken by: The team
			- Offered: Every break at {VENDCINT}
			- Lasts: The next tide
			- If failed: Nothing
			- Later maps: Node has more health and spawns further from player's spawn point
			- Pays: Pure Aura 3
			- Look: A node with a white crystal
			- Clashes: None
		{Keep the Basin Clean}
			- Kind: Guard
			- In-game line: No foe hurts the Basin this Tide
			- Numbers: no damage at all
			- Taken by: The team
			- Offered: Every break at {VENDCINT}
			- Lasts: The next tide
			- If failed: Nothing
			- Later maps: The same
			- Pays: Pure Aura 2
			- Look: A mop and bucket
			- Clashes: None
		{Beat the Clock}
			- Kind: Rush
			- In-game line: Clear the Tide with time to spare
			- Numbers: the last foe falls with at least 25% of the tide's clock left
			- Taken by: The team
			- Offered: Every break at {VENDCINT}
			- Lasts: The next tide
			- If failed: Nothing
			- Later maps: The same
			- Pays: Pure Aura 3
			- Look: A cracked stopwatch
			- Clashes: None
		{Mind the Vessels}
			- Kind: Guard
			- In-game line: No vessel drowns this Tide
			- Numbers: no vessel falls
			- Taken by: The team
			- Offered: Every break at {VENDCINT}
			- Lasts: The next tide
			- If failed: Nothing
			- Later maps: The same
			- Pays: Pure Aura 2
			- Look: A life ring
			- Clashes: None
		{Raze the Nest}
			- Kind: Hunt
			- In-game line: A halberd nest lands near the foes: destroy it before the Tide ends
			- Numbers: 3 to 7 tiles from an enemy core
			- Taken by: The team
			- Offered: Every break at {VENDCINT}, never on a Nesting Ground map
			- Lasts: The next tide
			- If failed: Nothing
			- Later maps: The same
			- Pays: Pure Aura 4
			- Look: A burning nest
			- Clashes: None
